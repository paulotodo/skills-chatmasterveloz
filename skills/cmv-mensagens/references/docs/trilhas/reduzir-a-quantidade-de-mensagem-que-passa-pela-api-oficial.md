# Reduzir a quantidade de mensagem que passa pela API oficial

- **Fonte:** https://clihelper.chatmasterveloz.com/docs/reduzir-a-quantidade-de-mensagem-que-passa-pela-api-oficial
- **Categoria:** Trilhas
- **Menu:** A cobrança do WhatsApp Oficial mudou › Reduzir a quantidade de mensagem que passa pela API oficial

---

🧩 **Quanto do seu atendimento precisa mesmo ser enviado pelo canal oficial?** Só o que passa pela API Oficial é cobrado pela Meta — e essa fatia é ajustável.

O nosso **Modo Híbrido** (API Oficial Coex + QR Code) reparte o envio: você escolhe o percentual que sai por uma conexão QR do mesmo número, que não passa pela Meta.
