# Visão Geral Agendamentos

- **Fonte:** https://clihelper.chatmasterveloz.com/docs/visao-geral-agendamentos
- **Categoria:** Recursos
- **Menu:** Agendamentos › Visão Geral Agendamentos

---

🧩 **Visão geral de Agendamentos** é o seu calendário central onde estão localizados todos os agendamentos.

![Visão Geral Agendamentos](https://clihelper.chatmasterveloz.com/docs-imagem/29383-agendamentos-visao-geral.jpg)

## Topo

⚡ **Cabeçalho de Controle:** no topo direito da tela, você encontra as ferramentas de navegação:

🔲 **Botão Atualizar:** para atualizar a listagem de agendamentos.

🔲 **+ NOVA AGENDAMENTO:** botão para iniciar o cadastro de um novo agendamento.

🔘 **Buscar Agendamento**: campo de texto para buscar um agendamento pelo nome, telefone, mensagens ou status.

## PARTE CENTRAL

⚡ **Filtros**

🔘 **Por Períodos**: filtre a lista de agendamentos por:  
- **Mês**: todos os agendamentos em visão de calendário.
- **Dia**: agendamentos do DIA visão de lista.
- **Histórico**: todos agendamentos em visão de lista.

⚡ **Lista de Agendamentos:** cada box representa um agendamento cadastrado no sistema, sendo composto por:

#### ⬅️ *do lado esquerdo*

◽ **Data e Hora do Disparo:** visualização rápida do quando a mensagem foi programada para envio.

#### ➡️ *do lado direito*

◽ **Contato:** destinatário da mensagem.

◽ **Etiqueta Status:** indica o Status do Envio (**Pendente** laranja, **Agendada** azul, **Enviada** verde, **Erro** vermelho).

◽ **Etiqueta Abriu Ticket:** (verde com ícone de "check" branco) indica se o agendamento foi configurado para abrir ticket.

◽ **Telefone:** número do destinatário.

◽ **Criado por:** atendente do sistema que criou esse agendamento.

◽ **Mensagem:** texto a ser enviado.

🔲 **Ícone Lápis:** botão para editar um agendamento.

🔲 **Ícone Lixeira:** botão para excluir um agendamento.
