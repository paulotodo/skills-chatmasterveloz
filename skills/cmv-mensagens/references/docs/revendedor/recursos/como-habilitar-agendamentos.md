# Agendamentos

- **Fonte:** https://revendedor.chatmasterveloz.com/docs/como-habilitar-agendamentos
- **Categoria:** Recursos
- **Menu:** Como Habilitar › Agendamentos

---

🧩 Ofereça **Agendamentos** de mensagens e lembretes internos, para o atendente programar um envio futuro em vez de depender da própria memória.

> **[RESUMO]**
>
> #### Resumo Prático
>
> ➡️ Habilite **Agendamentos** no menu **Configurações  ›  Planos**.
>
> ➡️ Acesse o menu **Agendamentos**, ou use o botão de agendamento dentro de um atendimento.
