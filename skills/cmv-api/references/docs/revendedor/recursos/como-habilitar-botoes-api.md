⭐ Módulo Botões.

🧩 Ofereça **botões interativos via API** nas conexões por QR Code, para o cliente responder tocando numa opção em vez de digitar.

> **[RESUMO]**
>
> #### Resumo Prático
>
> ➡️ Habilite **API Externa** no menu **Configurações  ›  Planos**.
>
> ➡️ Habilite **Botões** no menu **Configurações  ›  Planos**.
>
> ➡️ Escolha a biblioteca no campo **API Não Oficial**, no menu **Configurações  ›  Empresas  ›  abrir a empresa  ›  aba Avançado**.
>
> ➡️ Crie um token no menu **Conexões  ›  editar a Conexão  ›  aba Integrações  ›  Token**.
>
> ➡️ Use a documentação de API para montar as requisições com botões.
