# API

- **Fonte:** https://revendedor.chatmasterveloz.com/docs/como-habilitar-api
- **Categoria:** Recursos
- **Menu:** Como Habilitar › API

---

🧩 Ofereça integração por **API** entre a plataforma e outros sistemas do cliente, para criar atendimentos, enviar mensagens e consultar dados a partir de um sistema próprio.

> **[RESUMO]**
>
> #### Resumo Prático
>
> ➡️ Habilite **API Externa** no menu **Configurações  ›  Planos**.
>
> ➡️ Crie um token:
>
> **da Conexão**: no menu **Conexões  ›  editar a Conexão  ›  aba Integrações  ›  Token** (define sozinho por onde a mensagem é enviada).
>
> **ou da Empresa**: no menu **Configurações  ›  Token da Empresa** (a Conexão precisa ser informada em cada chamada, menos nas que só aceitam este token).
>
> ➡️ Use a documentação de API para montar as requisições.
