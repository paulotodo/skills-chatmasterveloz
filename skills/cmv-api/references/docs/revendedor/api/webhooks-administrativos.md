# Webhooks Administrativos

- **Fonte:** https://revendedor.chatmasterveloz.com/docs/webhooks-administrativos
- **Categoria:** APIs
- **Menu:** Webhooks Administrativos

---

🧩 O **Webhook Administrativo** avisa um sistema externo seu toda vez que algo acontece na plataforma inteira — em qualquer empresa, não em uma delas.

✅ Quando uma conexão muda de status;

✅ Quando uma empresa nova é criada.

![Ilustração de um evento na plataforma disparando um aviso para um sistema externo](https://revendedor.chatmasterveloz.com/docs-imagem/rev-270-webhook-explicacao-1024x509.jpg)

⚠️ **Apenas um campo, com uma URL.** Os eventos chegam no mesmo endereço, e é o seu sistema que os separa pelo conteúdo do aviso.
