# Pré-Requisitos das APIs

- **Categoria:** APIs
- **Menu:** APIs Administrativas › Pré-Requisitos das APIs

---

🧩 O que precisa estar no lugar para o cliente conseguir usar as APIs. São três itens, e dois deles são seus.

> **[RESUMO]**
>
> #### Resumo Prático
>
> ➡️ Habilite **API Externa** no menu **Configurações  ›  Planos**, no plano que a empresa usa.
>
> ➡️ O token é passo do cliente: ele cria no menu **Conexões  ›  editar a Conexão  ›  aba Integrações  ›  Token**.

## A biblioteca decide quais chamadas existem

O campo **API Não Oficial** vale para as conexões por QR Code, e a escolha muda o que a API entrega — nem toda chamada existe nas duas bibliotecas. O campo mostra o nome técnico de cada uma, **Baileys** e **APIdoZap Pro**; na documentação do cliente elas aparecem como **Básica** e **Pro**.

> **[DUVIDAS]**
>
> #### Dúvidas Comuns
>
> **O cliente diz que a chamada devolve erro de autenticação.** Conferir também se **API Externa** está mesmo marcada no plano que aquela empresa usa, e não em outro.
