# Adicionar Tag

- **Fonte:** https://clihelper.chatmasterveloz.com/docs/adicionar-tag
- **Categoria:** Fora do menu
- **Menu:** (não aparece em nenhum menu)

---

🧩 **Adicionar Nova Tag** é o procedimento para cadastrar uma nova etiqueta no sistema, permitindo que sua equipe use para classificar tickets, protocolos e oportunidades.

☑️ **Expansão:** crie novos identificadores conforme sua operação cresce (ex: uma nova campanha de marketing ou um novo produto).

☑️ **Ajuste de Processo:** insira novas etapas no seu fluxo de trabalho.

> **[RESUMO]**
>
> #### Resumo Prático
>
> ➡️ Acesse o menu **Tags**.
>
> ➡️ Clique no botão **+ Nova Tag** no canto superior direito.
>
> ➡️ Preencha os **campos** e clique no botão **Adicionar**.

## Como adicionar uma Tag

Acesse o menu → Tags > + Nova Tag

O formulário tem três abas: **Geral**, **Pixel Meta** e **Remarketing**. Os campos abaixo são os da aba **Geral**; a aba **Pixel Meta** aparece conforme o seu plano.

![Formulário adicionar Tag - Aba Geral](https://clihelper.chatmasterveloz.com/docs-imagem/21113-tags-adicionar-formulario.jpg)**⚡ GERAL**

**"Informações Básicas":**

🔘 **Nome:** digite o título da etiqueta / tag.

🔘 **Cor:** selecione uma cor para rápida identificação visual.

**"Configurações Avançadas":**

🔘 **Tipo de Tag:** selecione a categoria correta: **- Atendimento:** para classificar o chat. **- Encerramento:** para motivos de finalização. **- CRM:** para oportunidades no pipeline de vendas.

🔘 **Kanban:** selecione **Habilitado** se quiser que esta tag se torne uma coluna no seu quadro de gestão visual (opção válida apenas para tags do tipo *Atendimento*).

🔘 **Ordenação:** defina a prioridade de exibição. No Kanban, números menores aparecem primeiro (da esquerda para a direita). Números repetidos são aceitos — quando duas tags ficam com o mesmo número, o Kanban desempata pela ordem alfabética do nome.

🔲 Para finalizar, clique em **Adicionar**.

> **[DUVIDAS]**
>
> ### Dúvidas Comuns
>
> **Posso criar duas tags com o mesmo nome?** Não. O sistema bloqueia o cadastro de uma tag com nome que já existe. Para separar tags parecidas, use nomes diferentes — e a cor para a identificação visual.
>
> **A tag nova aparece para todos os usuários?** Sim, assim que salva, a tag fica disponível para todos os atendentes que têm permissão de visualizar tags.
