# Telegram

- **Fonte:** https://clihelper.chatmasterveloz.com/docs/telegram
- **Categoria:** Fora do menu
- **Menu:** (não aparece em nenhum menu)

---

🧩 No **Telegram**, quem atende é um bot: você cria o bot no próprio Telegram, cola o token dele aqui, e as conversas que chegam ao bot caem na tela de atendimento como qualquer outro canal.

> **[RESUMO]**
>
> #### Resumo Prático
>
> ➡️ No Telegram, procure **@BotFather**, envie **/newbot** e siga as instruções. Copie o token que ele devolver.
>
> ➡️ Acesse o menu **Conexões**, abra **Ações** e escolha **Adicionar Telegram**.
>
> ➡️ Preencha o **Nome da Conexão**, cole o **Token do Bot** e marque um Setor. Clique em **Criar Conexão**.

## Aba Geral

A própria aba ensina, em três passos: *abra o Telegram e pesquise por @BotFather; envie o comando /newbot e siga as instruções; copie o Token HTTP API gerado e cole abaixo*.

🔘 **Nome da Conexão:** nas palavras da tela, *nome interno para identificar esta conexão*.

🔘 **Token do Bot (BotFather):** o token que o BotFather entregou. Nas palavras da tela: *Token HTTP API fornecido pelo @BotFather*. Trate como senha.

🔘 **Setores:** para onde as conversas vão.

## Abas Mensagens e Integrações

As mensagens automáticas e os endereços de integração, no mesmo molde das outras conexões.

A conexão de Telegram começa a funcionar assim que é criada, sem reiniciar nada.

⚠️ O token dá controle do bot. Quem tem o token responde em nome dele. Se vazar, gere outro no BotFather com **/revoke** e atualize aqui.

> **[DUVIDAS]**
>
> #### Dúvidas Comuns
>
> **O cliente precisa de algo especial?** Não. Ele procura o nome do bot no Telegram e escreve, como para qualquer contato.
>
> **Posso usar a minha conta pessoal do Telegram?** Não. O Telegram só permite atendimento por bot.
>
> **Criei e nada chega.** Confira o Setor. E confirme, no BotFather, que o token colado é o do bot certo.
