# API Oficial Nativa

- **Fonte:** https://revendedor.chatmasterveloz.com/docs/api-oficial-nativa
- **Categoria:** Trilhas
- **Menu:** Meta › API Oficial Nativa

---

🧩 **A Chegada da API Oficial Nativa** marca um novo capítulo na nossa plataforma. Agora, o cliente final pode conectar o WhatsApp Business API (WABA) diretamente pelo nosso painel, utilizando o fluxo de login oficial da Meta (Embedded Signup), sem gambiarras e sem depender de integradores externos.

Opções de **Facilidade Imediata** (Modelo Inc) ou a **Marca Total** (Modelo Whitelabel Tech Provider).

> **[RESUMO]**
>
> #### Resumo Prático
>
> ➡️ **Opção A (Modelo Inc):** nossa plataforma usa uma estrutura genérica. É "Plug and Play". Cliente **visualiza o nome de uma empresa diferente** ao realizar o login de integração.
>
> ➡️ **Opção B (Modelo WhiteLabel):** Cliente **visualiza o nome da nossa marca** ao realizar o login de integração.

## **Entendendo os dois Modelos**

**⚡ Modelo Inc (Facilitado)**

*O jeito mais rápido de começar.* Neste modelo é utilizado uma empresa diferente como tech provider. O cliente vê uma tela de login neutra/genérica na hora de conectar.

**⚡ Modelo White Label (Tech Provider Próprio)**

*O jeito "Dono do Jogo"*: vale **depois** que a nossa marca se torna Provedor de Tecnologia na META, com a **empresa** verificada e o **Tech Provider** e o **App** aprovados.

O cliente vê uma tela de login do Facebook com o **NOSSO NOME e LOGOTIPO**.

## **Como adicionar uma Conexão API Oficial**

Independente do modelo utilizado, acesse o menu **Conexões  ›  3 pontos  ›  Adicionar WhatsApp Oficial** e siga com o login no facebook no popup.

> **[DUVIDAS]**
>
> #### Dúvidas Comuns
>
> **Posso começar no Modelo Inc e mudar depois?** Sim! É o jeito rápido de começar antes da META aprovar a nossa marca. Mas depois opte sempre pelo modelo WhiteLabel.
>
> **Posso utilizar os dois modelos ao mesmo tempo?** Não, dá erros e não existe motivo para usar dessa forma. Assim que aprovado nosso tech provider whitelabel na META, utilize somente esse modelo.
