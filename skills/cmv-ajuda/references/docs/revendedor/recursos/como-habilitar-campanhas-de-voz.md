# Campanhas de Voz

- **Fonte:** https://revendedor.chatmasterveloz.com/docs/como-habilitar-campanhas-de-voz
- **Categoria:** Recursos
- **Menu:** Como Habilitar › Campanhas de Voz

---

⭐ Módulo Ligações API QR Code.

🧩 Ofereça **envio de ligações gravadas em massa** por meio de **Campanhas de Voz**, usando a mesma lista de contatos das campanhas de texto.

> **[RESUMO]**
>
> #### Resumo Prático
>
> ➡️ Marque **Campanhas Habilitadas** no menu **Configurações  ›  Empresas  ›  abrir a empresa  ›  aba Configurações**.
>
> ➡️ Habilite **Campanhas** no menu **Configurações  ›  Planos**.
>
> ➡️ Habilite **Ligações no Zap** no menu **Configurações  ›  Planos**.
>
> ➡️ Habilite **Acesso a Campanhas** no menu **Equipe  ›  editar o usuário**.
