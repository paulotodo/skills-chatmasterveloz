# Chat Interno

- **Fonte:** https://revendedor.chatmasterveloz.com/docs/como-habilitar-chat-interno
- **Categoria:** Recursos
- **Menu:** Como Habilitar › Chat Interno

---

🧩 Ofereça **Chat Interno** para a equipe conversar entre si dentro da plataforma, sem sair para outro aplicativo e sem misturar com as conversas de cliente.

> **[RESUMO]**
>
> #### Resumo Prático
>
> ➡️ Habilite **Chat Interno** no menu **Configurações  ›  Planos**.
>
> ➡️ Acesse o menu **Chat Interno** para criar as conversas.
