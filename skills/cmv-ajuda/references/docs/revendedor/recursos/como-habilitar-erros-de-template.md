# Erros de Template

- **Fonte:** https://revendedor.chatmasterveloz.com/docs/como-habilitar-erros-de-template
- **Categoria:** Recursos
- **Menu:** Como Habilitar › Erros de Template

---

🧩 Ofereça **Erros de Template**: todo template recusado pela Meta fica gravado com o que foi enviado, a resposta da Meta e a diferença entre os dois — quantas variáveis faltaram, se a mídia do cabeçalho não foi, se o botão de URL ficou sem parâmetro.

> **[RESUMO]**
>
> #### Resumo Prático
>
> ➡️ Não há o que habilitar no menu **Configurações  ›  Planos**: a tela aparece sozinha para a empresa que tem conexão de API Oficial, e não aparece para quem não tem.
>
> ➡️ Acesse o menu **Erros de Template**, ou use o botão **Erros de template** no card da conexão oficial, que já abre filtrado naquela conexão.
>
> ➡️ Visível apenas para admin e supervisor. O token da conexão nunca é gravado.
