# Chat Externo por Link (Modo Alternativo )

- **Fonte:** https://revendedor.chatmasterveloz.com/docs/como-habilitar-chat-externo-por-link
- **Categoria:** Recursos
- **Menu:** Como Habilitar › Chat Externo por Link (Modo Alternativo )

---

🧩 O **Modo Alternativo (chat externo por link)** dá ao contato um endereço para conversar numa página externa mas que abre dentro do WhatsApp, continuando a conversa já existente. Não é o **Chat Externo**, que é uma conexão própria, com página de entrada para o site.

> **[RESUMO]**
>
> #### Resumo Prático
>
> ➡️ Habilite **API Externa** no menu **Configurações  ›  Planos**.
>
> ➡️ Habilite **Botões** no menu **Configurações  ›  Planos**.
>
> ➡️ Acesse o menu **Configurações  ›  Empresas**, edite a empresa e abra a aba **Configurações**. Em **Permissões e Bloqueios**, ligue **Modo Alternativo (Chat Externo por Link)**.
>
> ➡️ No menu **Conexões**, edite a conexão de API Oficial e abra a aba **Geral**.
>
> ➡️ Ligue **Modo alternativo (chat externo por link)**, preencha os textos e salve.
