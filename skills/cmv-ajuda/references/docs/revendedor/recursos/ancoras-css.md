# Âncoras CSS

- **Fonte:** https://revendedor.chatmasterveloz.com/docs/ancoras-css
- **Categoria:** Recursos
- **Menu:** Downloads › Âncoras CSS

---

🧩 Lista das **âncoras CSS** da plataforma de atendimento: as classes e os atributos que cada parte da tela expõe para você mudar a aparência sem tocar no código.

Com a lista em mãos, escreva o CSS e cole no menu **Configurações  ›  Cores**, que vale para a instância inteira — ou, para uma empresa só, no campo **CSS desta empresa**, no menu **Configurações  ›  Empresas  ›  card da empresa  ›  aba Configurações**.

> **[DICA]**
>
> #### Dica
>
> Acesse as âncoras do CSS em `https://seu-frontend/css-docs`, trocando `seu-frontend` pelo endereço da sua instância.
>
> A página **/css-docs** é atualizada a cada versão da plataforma e mostra também em qual campo colar cada CSS, as convenções que valem para todas as telas, exemplos prontos e o que mudou em cada versão.
