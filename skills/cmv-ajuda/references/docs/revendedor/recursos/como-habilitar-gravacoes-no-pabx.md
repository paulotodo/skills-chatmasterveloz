# Gravações no PABX

- **Fonte:** https://revendedor.chatmasterveloz.com/docs/como-habilitar-gravacoes-no-pabx
- **Categoria:** Recursos
- **Menu:** Como Habilitar › Gravações no PABX

---

🧩 Traga as **gravações das ligações** para dentro do menu **Chamadas** da plataforma.

> **[RESUMO]**
>
> #### Resumo Prático
>
> ➡️ No sistema de **PABX**, abra a listagem e **edite** o PABX desejado.
>
> ➡️ Em **Gravações de Chamadas (S3)**, marque **Habilitar gravação de todas as chamadas**.
>
> ➡️ Preencha as **informações de seu S3**, para as gravações começarem a ser salvas.
>
> ➡️ Marque **Habilitar Webhook de Gravações**, para sincronizar o armazenamento com a plataforma.
>
> ➡️ Na URL do **webhook 2**, use o endereço `https://{backendUrl}/api/messages/callwebhook`.
>
> ➡️ No campo de token, informe o **token de uma Conexão** dessa empresa.
>
> ➡️ De volta ao PABX do cliente, abra **Gravações** e use o botão de **Diagnóstico** para validar.
