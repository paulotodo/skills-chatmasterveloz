# Web Chat (hub)

- **Fonte:** https://revendedor.chatmasterveloz.com/docs/como-habilitar-web-chat-hub
- **Categoria:** Recursos
- **Menu:** Como Habilitar › Web Chat (hub)

---

⭐ Canais do Hub.

🧩 Tenha uma conexão de **WebChat pelo hub** instalada no site do cliente, com as mensagens caindo na plataforma como atendimento normal.

> **[RESUMO]**
>
> #### Resumo Prático
>
> ➡️ Habilite **Notificame HUB** no menu **Configurações  ›  Planos**. É necessário solicitar a conta e os créditos de canal ao suporte antes.
>
> ➡️ Cole o código da conta do hub no menu **Integrações  ›  OmniChannel  ›  Token de Integração**.
>
> ➡️ Na conta do hub, crie o Web Chat e personalize as configurações.
>
> ➡️ No Web Chat criado, use os três pontos, abra o script e copie o código para colar no site.
>
> ➡️ Na plataforma, abra o menu **Conexões**, use os três pontos e escolha **Adicionar Contas OmniChannel**.
