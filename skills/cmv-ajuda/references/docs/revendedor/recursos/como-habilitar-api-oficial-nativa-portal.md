# API Oficial Nativa (Portal)

- **Fonte:** https://revendedor.chatmasterveloz.com/docs/como-habilitar-api-oficial-nativa-portal
- **Categoria:** Recursos
- **Menu:** Como Habilitar › API Oficial Nativa (Portal)

---

🧩 Ofereça **API Oficial** aos seus clientes usando o provedor do Portal, sem precisar do próprio cadastro de provedor junto à Meta.

> **[RESUMO]**
>
> #### Resumo Prático
>
> ➡️ No controlador da instância, habilite o WABA Inc — o botão fica ao lado do ícone de olho.
>
> ➡️ De volta à plataforma, habilite **WABA INC** no menu **Configurações  ›  Planos**.
>
> ⚠️ **Não habilite WABA WL e WABA INC na mesma instância.** São dois caminhos para a mesma funcionalidade, e manter os dois ligados deixa o comportamento imprevisível. Escolha um.
>
> ➡️ No menu **Conexões**, use os três pontos e escolha **Adicionar WhatsApp Oficial**. Se a opção não aparecer, reinicie as conexões antes.
>
> ➡️ Conclua o login do Facebook na plataforma e instale o número como API Oficial.
>
> ⚠️ Para migrar um número que está em outro provedor, pode ser necessário adicionar o ID `263131720791091` como parceiro na gestão do número.
