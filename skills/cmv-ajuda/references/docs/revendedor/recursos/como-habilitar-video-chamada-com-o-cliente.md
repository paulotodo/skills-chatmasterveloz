# Video Chamada com o Cliente

- **Fonte:** https://revendedor.chatmasterveloz.com/docs/como-habilitar-video-chamada-com-o-cliente
- **Categoria:** Recursos
- **Menu:** Como Habilitar › Video Chamada com o Cliente

---

⭐ Módulo Chamadas (Cliente).

🧩 Ofereça **chamadas de áudio, vídeo e compartilhamento de tela** com o cliente, pela videochamada aberta dentro do atendimento.

> **[RESUMO]**
>
> #### Resumo Prático
>
> ➡️ Habilite **Videochamada com o cliente** no menu **Configurações  ›  Planos**.
>
> ➡️ Para usar um servidor de mídia próprio no lugar do padrão do sistema, cadastre-o no menu **Configurações  ›  Servidor de mídia**. É opcional: sem ele, as chamadas usam o servidor padrão.
