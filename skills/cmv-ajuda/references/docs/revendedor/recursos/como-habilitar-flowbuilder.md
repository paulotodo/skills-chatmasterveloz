# FlowBuilder Nativo

- **Fonte:** https://revendedor.chatmasterveloz.com/docs/como-habilitar-flowbuilder
- **Categoria:** Recursos
- **Menu:** Como Habilitar › FlowBuilder Nativo

---

🧩 Ofereça **construção de fluxos** de automação: o cliente desenha o roteiro do atendimento com perguntas, condições e respostas, e o fluxo conversa antes de qualquer pessoa entrar.

> **[RESUMO]**
>
> #### Resumo Prático
>
> ➡️ Habilite **FLOW** no menu **Configurações  ›  Planos**.
>
> ➡️ Crie o fluxo no menu **FlowBuilder Nativo**.
>
> ➡️ Vincule o fluxo a uma Conexão, a uma Tag, a uma Resposta Rápida, a uma Campanha, à API ou a um webhook.
>
> ➡️ Alguns blocos dependem de outros módulos ou planos: **CRM** para o bloco Oportunidade, **Automação Instagram** para Responder Comentário e É Seguidor?, **Botões** para os botões nas conexões por QR Code, **GPT Assistant** para o bloco GPT Assistant, **Typebot / Flowise** para o bloco Typebot e **WPW** para o Pixel META.
>
> ⚠️ Fluxo criado e não vinculado não roda. O vínculo é o que diz ao sistema quando chamar aquele roteiro.
