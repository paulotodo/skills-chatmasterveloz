# Web Chat Nativo

- **Fonte:** https://revendedor.chatmasterveloz.com/docs/como-habilitar-web-chat-nativo
- **Categoria:** Recursos
- **Menu:** Como Habilitar › Web Chat Nativo

---

🧩 Ofereça uma conexão **WebChat** instalada no site do cliente, com as mensagens caindo na plataforma como qualquer outro atendimento.

> **[RESUMO]**
>
> #### Resumo Prático
>
> ➡️ Habilite **WebChat** no menu **Configurações  ›  Planos**.
>
> ➡️ No menu **Conexões**, abra os três pontos no canto superior direito e escolha **Adicionar WebChat**.
>
> ➡️ Clique no lápis da conexão criada para ajustar a aparência e copiar o **código de instalação** para colar no site.
