# Chamadas no Chat Interno

- **Fonte:** https://revendedor.chatmasterveloz.com/docs/como-habilitar-chamadas-no-chat-interno
- **Categoria:** Recursos
- **Menu:** Como Habilitar › Chamadas no Chat Interno

---

⭐ Módulo Chamadas (Equipe).

🧩 Ofereça **chamadas de áudio, vídeo e compartilhamento de tela** entre a equipe, dentro das conversas do **Chat Interno**.

> **[RESUMO]**
>
> #### Resumo Prático
>
> ➡️ Habilite **Chat Interno** no menu **Configurações  ›  Planos**. As chamadas acontecem nas conversas dele.
>
> ➡️ Habilite **Chamadas no chat interno** no menu **Configurações  ›  Planos**.
>
> ➡️ Para usar um servidor de mídia próprio no lugar do padrão do sistema, cadastre-o no menu **Configurações  ›  Servidor de mídia**. É opcional: sem ele, as chamadas usam o servidor padrão.
