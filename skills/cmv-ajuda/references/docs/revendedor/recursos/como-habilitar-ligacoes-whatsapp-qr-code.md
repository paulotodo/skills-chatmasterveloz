# Ligações WhatsApp QR Code

- **Fonte:** https://revendedor.chatmasterveloz.com/docs/como-habilitar-ligacoes-whatsapp-qr-code
- **Categoria:** Recursos
- **Menu:** Como Habilitar › Ligações WhatsApp QR Code

---

⭐ Módulo Ligações API QR Code.

⭐ Módulo VoIP / Discador (para ligar e receber dentro da plataforma).

🧩 Ofereça **ligações pelo WhatsApp** nas conexões por QR Code, integrando o PABX digital do cliente à plataforma.

> **[RESUMO]**
>
> #### Resumo Prático
>
> ➡️ Habilite **Ligações no Zap** no menu **Configurações  ›  Planos**.
>
> ➡️ Habilite **Ligações VOIP** no menu **Configurações  ›  Planos**.
>
> ➡️ Configure a Conexão e cada perfil da equipe como um ramal.
>
> ⚠️ São dois módulos com papéis diferentes: o primeiro libera a ligação pelo WhatsApp, o segundo é o que permite atender e discar de dentro da plataforma.
