# Iniciar Conversa com um Contato

- **Fonte:** https://clihelper.chatmasterveloz.com/docs/iniciar-conversa-com-um-contato
- **Categoria:** Recursos
- **Menu:** Contatos › Iniciar Conversa com um Contato

---

Para **iniciar uma conversa** com um contato, acesse o menu →Contatos > Ícone WhatsApp

![imagem](https://clihelper.chatmasterveloz.com/docs-imagem/20232-contatos-iniciar-1024x176.jpg)Verifique o Status desse atendimento, se estiver **Disponível** defina uma **Fila** e uma **Conexão** para iniciar.

![imagem](https://clihelper.chatmasterveloz.com/docs-imagem/20232-contatos-novo-atendimento.jpg)Se o contato já estiver em atendimento, o Status informará a **Fila**, **Conexão** e **atendente**.

![imagem](https://clihelper.chatmasterveloz.com/docs-imagem/20232-contatos-em-atendimento.jpg)

#### em Chats

Você também pode iniciar uma nova conversa diretamente na tela de Chat, ao clicar no botão **NOVO** para iniciar um **Ticket**, digite o número WhatsApp do contato. Caso ele não esteja cadastrado no sistema, a opção **Adicionar** aparecerá.

![imagem](https://clihelper.chatmasterveloz.com/docs-imagem/20232-chat-iniciar-conversa-1024x920.jpg)
