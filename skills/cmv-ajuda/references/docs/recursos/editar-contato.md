# Editar Contato

- **Fonte:** https://clihelper.chatmasterveloz.com/docs/editar-contato
- **Categoria:** Recursos
- **Menu:** Contatos › Editar Contato

---

Para **editar** um contato, acesse o menu → Contatos > Ícone Lápis

![imagem](https://clihelper.chatmasterveloz.com/docs-imagem/20234-contatos-editar-1024x182.jpg)

> **[ATENCAO]**
>
> #### Atenção
>
> Não é permitido alterar o número de telefone do contato.
>
> Outro local que é possível alterar um contato é diretamente no chat.
>
> Ao clicar no nome do contato, uma coluna aparecerá na direita, com as informações do contato e o botão "**Editar Contato**"
>
> ![imagem](https://clihelper.chatmasterveloz.com/docs-imagem/20234-contato-editar-chat-1024x538.jpg)

#### Contatos no WhatsApp

Para cadastrar telefones de WhatsApp dentro do sistema utilize o padrão:

**Código do País + DDD + Telefone** (somente número, sem traço, espaço ou caracteres especiais) ex: 5511999888777

↗️ para DDDs **acima** de 30 número whatsapp com 8 dígitos

↘️ para DDDs **abaixo** de 30 número whatsapp com 9 dígitos
