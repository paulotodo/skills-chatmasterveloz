## Aplicativo

Nossa Plataforma na palma de sua mão

PWA (Progressive Web App) é um tipo de aplicação web projetada para fornecer uma experiência de usuário semelhante a um aplicativo nativo, mas sem a necessidade de ser baixada ou instalada a partir de uma loja de apps.

Com nosso PWA:

**✅** Você pode **acessar** nossa plataforma diretamente pelo seu celular, com a mesma experiência de um aplicativo.

**✅** Você pode "instalar" no seu dispositivo como se fosse um aplicativo nativo, criando um ícone na tela inicial.
