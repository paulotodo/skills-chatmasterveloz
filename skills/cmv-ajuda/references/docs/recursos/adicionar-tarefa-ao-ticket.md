# Adicionar Tarefa ao Ticket

- **Fonte:** https://clihelper.chatmasterveloz.com/docs/adicionar-tarefa-ao-ticket
- **Categoria:** Recursos
- **Menu:** Tarefas › Adicionar Tarefa ao Ticket

---

🧩 **Adicionar Tarefa ao Ticket** agiliza o fluxo de trabalho permitindo criar demandas sem sair da tela de atendimento, mantendo o foco no cliente enquanto organiza os próximos passos.

☑️ **Contexto Automático:** a tarefa já nasce vinculada ao cliente / conversa atual.

☑️ **Delegação Imediata:** atribua a responsabilidade da tarefa para outro atendente diretamente na criação.

> **[RESUMO]**
>
> #### Resumo Prático
>
> ➡️ Abra o **Ticket (conversa)** do cliente desejado.
>
> ➡️ Na parte de Ações do Ticket clique no ícone (📝) **Nova Tarefa**.
>
> ➡️ Preencha os **campos** e clique no botão **Criar Tarefa**.

## Como adicionar uma Tarefa ao Ticket

Acesse o menu **Chats**, abra o ticket do cliente e clique no ícone **Nova Tarefa** para preencher o formulário:

![Formulário para adicionar uma tarefa ao ticket](https://clihelper.chatmasterveloz.com/docs-imagem/26232-tarefas-adicionar-ao-ticket.jpg)

🔘 **Título:** digite o nome da tarefa de forma clara.

🔘 **Descrição:** o campo descrição é opcional, mas útil para detalhar instruções.

🔘 **Prioridade:** Selecione entre **Baixa**, **Média** ou **Alta**. *Isso criará uma etiqueta colorida (TAG) na lista de tarefas, facilitando a identificação visual do que é urgente.*

🔘 **Data de Vencimento:** selecione o dia limite para a conclusão da atividade.

🔘 **Atribuir para:** Selecione o **Atendente** que será o responsável pela execução dessa tarefa.

🔘 **Os demais campos:** o formulário é o mesmo do menu **Tarefas**, com **Checklist**, **Tipo**, **Horários**, **Notificar antes (minutos)**, **Repetir** e **Anexos**. Com o **Tipo** **Reunião**, aparece também a **Sala da reunião**, que diz onde a reunião acontece.

🔲 Para finalizar, clique em **Criar Tarefa**.

![Tarefa vinculada ao ticket na lista de tarefas](https://clihelper.chatmasterveloz.com/docs-imagem/26232-tarefa-vinculada-ao-ticket.jpg)

A tarefa cadastrada ao ticket aparece no menu **Tarefas**, na lista de tarefas, com uma indicação referente ao ID do ticket. Um ícone de ↗️ facilita o acesso rápido ao ticket.

> **[DUVIDAS]**
>
> #### Dúvidas Comuns
>
> **O cliente visualiza que criei uma tarefa?** Não, a criação de tarefas é um processo interno e invisível para o cliente.
>
> **A tarefa some se o atendimento for finalizado?** Não, a tarefa permanece registrada e vinculada ao histórico do cliente, podendo ser consultada mesmo após o ticket ser encerrado (Resolvido).
>
> **Dá para marcar uma reunião com o cliente pela tarefa do ticket?** Dá. No formulário da **Nova Tarefa**, escolha o **Tipo** **Reunião** e, no campo **Sala da reunião**, onde ela acontece.
