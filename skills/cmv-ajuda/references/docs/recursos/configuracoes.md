# Configurações

- **Fonte:** https://clihelper.chatmasterveloz.com/docs/configuracoes
- **Categoria:** Recursos
- **Menu:** Configurações

---

🧩 Já aconteceu de um atendente não conseguir abrir conversa com um contato, de o cliente receber duas mensagens de boas-vindas, ou de um grupo de WhatsApp simplesmente não aparecer — e ninguém saber onde mexer? Quase sempre a resposta está numa opção desta tela.

**Configurações** é onde se define como a plataforma se comporta para a sua empresa inteira: o que o atendente pode ver e fazer, como o menu automático conversa com o cliente, que som toca, o que viaja numa transferência, e como a empresa se liga a serviços de fora.

## Como esta tela se comporta

![image.png](https://clihelper.chatmasterveloz.com/docs-imagem/ed-6ab181271fece.png)

➡️ **Cada opção salva sozinha ao ser alterada.** Não há botão Salvar. Isso significa que não existe "cancelar" — o que você trocou já valeu.

➡️ **Quase tudo aqui é da empresa inteira.** O que é por pessoa fica no cadastro do usuário, no menu **Equipe**; o que é por canal fica no menu **Conexões**.

➡️ **Quem já estava logado continua vendo a interface anterior** até atualizar a página. Vale para permissões, sons e visualização.

> **[DUVIDAS]**
>
> #### Dúvidas Comuns
>
> **Mudei uma opção e nada aconteceu.** Peça para o atendente sair e entrar de novo. O que esta tela define é lido quando a sessão começa.
>
> **Só administrador vê Configurações?** Sim. Supervisor e atendente não têm o menu, e o endereço direto redireciona para a lista de atendimentos.
