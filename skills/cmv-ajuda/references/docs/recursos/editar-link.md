# Editar Link

- **Fonte:** https://clihelper.chatmasterveloz.com/docs/editar-link
- **Categoria:** Recursos
- **Menu:** Gestão de Links › Editar Link

---

🧩 **A Edição de Links** é o verdadeiro "salva-vidas" das suas campanhas de marketing.

Em vez de precisar entrar no Facebook Ads, no Instagram e no seu site para trocar todos os links quando um número de WhatsApp é bloqueado ou alterado, você simplesmente edita o destino do link aqui dentro da plataforma. O link público (a URL curta que o cliente clica) continua exatamente o mesmo, mas o destino por trás dele é atualizado instantaneamente.

☑️ **Manutenção Rápida:** Troque o número de destino em segundos se o seu celular oficial mudar ou cair.

☑️ **Testes A/B:** Altere a "Mensagem" pré-definida para testar qual texto converte mais leads.

☑️ **Controle de Campanhas:** Desative temporariamente um link quando uma promoção acabar, sem precisar excluí-lo definitivamente do sistema.

> **[RESUMO]**
>
> #### Resumo Prático
>
> ➡️ Acesse o menu **Gestão de Links**.
>
> ➡️ Clique no ícone **lápis** (✏️) do Link.
>
> ➡️ Edite os **campos** desejados e clique no botão **Salvar**.

## Como editar um Link

Acesse o menu → Gestão de Links > ícone Lápis do link

![Formulário de Edição na Gestão de Links](https://clihelper.chatmasterveloz.com/docs-imagem/28915-gestao-de-link-formulario-editar.jpg)**🔘 Nome do Link:** renomeie o nome do link (somente você enxerga esse nome, seu cliente não).

🔘 **Número do WhatsApp:** altere o número do whatsapp de destino. Siga o padrão internacional (somente números DDI DDD Número)

**🔘 Mensagem:** (opcional) atualize o texto gatilho.

⚡ **Integração com Pixel da Meta (Opcional)**

🔘 **Pixel ID:** insira o ID (identificador) do seu pixel. (**tutorial aqui**)

🔘 **Access Token:** cole o token de acesso da API de Conversões. (**tutorial aqui**)

🔘 **Link Ativo:** marque ou desmarca o status do Link.

🔲 Para finalizar, clique em **Salvar**.

> **[DUVIDAS]**
>
> ### Dúvidas Comuns
>
> **Se eu editar o número, a URL curta (o link que o cliente clica) vai mudar?** Não! Essa é a grande mágica. A URL curta (ex: .../L/89e0qner) permanece idêntica. Você não precisa pedir para o seu gestor de tráfego pausar os anúncios para trocar o link.
>
> **Quanto tempo demora para a edição funcionar?** A atualização é em tempo real. Assim que você clica em Salvar, o próximo cliente que clicar no link já será direcionado para o número novo.
>
> **Os cliques antigos (Analytics) são zerados quando eu edito o link?** Não, o histórico de cliques é mantido para você não perder os dados da campanha.

> **[ERROS]**
>
> ## Erros Comuns
>
> **Fechar a janela sem salvar:** Fazer todas as alterações no número e na mensagem, mas clicar no "X" no canto superior direito em vez de clicar no botão **SALVAR**. As alterações serão perdidas.
>
> **Esquecer de avisar a automação (FlowBuilder):** Editar a "Mensagem" pré-definida no link e esquecer de ir lá no FlowBuilder alterar a "Condição" que lia a mensagem antiga. O cliente vai enviar o texto novo e o robô não vai reconhecer o gatilho.
>
> **Excluir o link em vez de desativá-lo:** Clicar na lixeira (Excluir) para parar uma campanha. Ao fazer isso, você perde todo o histórico do Analytics. O correto para pausar temporariamente é apenas Editar e desmarcar a chave **"Link Ativo"**.
