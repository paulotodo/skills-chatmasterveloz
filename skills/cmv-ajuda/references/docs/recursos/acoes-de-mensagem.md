# Ações de Mensagem

- **Fonte:** https://clihelper.chatmasterveloz.com/docs/acoes-de-mensagem
- **Categoria:** Recursos
- **Menu:** Chats / Tickets › Ações de Mensagem

---

![imagem](https://clihelper.chatmasterveloz.com/docs-imagem/16527-chats-acoes-de-mensagem-1024x541.jpg)No rodapé do chat temos diversas opções para enviar uma mensagem:

Ao clicar no **(+)** temos as opções de:

**Emoji, Envio de Arquivo, Assinar, Comunicação Interna**

Logo abaixo o campo de **Envio de Texto** e o botão para **Envio de Áudio**.

## Emoji

![imagem](https://clihelper.chatmasterveloz.com/docs-imagem/16527-envio-mensagem-emoji-1024x363.jpg)Você pode enviar **Emoji** nas conversas.

## Envio de Arquivo

![imagem](https://clihelper.chatmasterveloz.com/docs-imagem/16527-envio-arquivo-1024x150.jpg)Envie **arquivos** PDF, imagens e outros.

**Dica**: é possível arrastar um ou mais arquivos em cima do ícone de **(+)** para realizar o envio de forma mais rápida.

Após o upload você pode opcionalmente adicionar legendas.

![imagem](https://clihelper.chatmasterveloz.com/docs-imagem/16527-envio-arquivos-legenda.jpg)

## Assinar

![imagem](https://clihelper.chatmasterveloz.com/docs-imagem/16527-envio-assinatura-1024x151.jpg)Envia o **nome do atendente** antes de toda mensagem.

Ao ativar essa opção, o campo de chat ficará na cor **Amarela** para indicar que a assinatura está ativada na mensagem.

**Atenção**: O ícone de habilitar ou desabilitar Assinaturas pode não estar visível conforme configurações do administrador.

## Comunicação Interna (Whisper)

![imagem](https://clihelper.chatmasterveloz.com/docs-imagem/16527-envio-mensagem-interna-1024x150.jpg)Envie uma **mensagem interna**, visualizada somente dentro da plataforma. O cliente **não** receberá essa mensagem.

Ao ativar a comunicação interna, o campo de mensagem ficará **azul** para indicar que o texto será enviado internamente.

![imagem](https://clihelper.chatmasterveloz.com/docs-imagem/16527-texto-mensagem-interna-exemplo.jpg)Veja um exemplo de uma mensagem enviada como comunicação interna.

## Envio de Texto

![imagem](https://clihelper.chatmasterveloz.com/docs-imagem/16527-envio-mensagem-texto-1024x44.jpg)Digite para enviar um texto.

**Dica:** Para enviar "Respostas Rápidas" digite / e na sequência a primeira letra do nome de uma das respostas rápidas cadastradas.

![imagem](https://clihelper.chatmasterveloz.com/docs-imagem/16527-envio-mensagem-texto-enviar-1024x45.jpg)Quando começar a digitar, um ícone de "Avião" irá aparecer no lugar do ícone de "Áudio".

Clique nele para enviar sua mensagem, ou utilize a tecla **ENTER**.

Para quebra de linhas, utilize o atalho **SHIFT + ENTER**

## Envio de Áudio

![imagem](https://clihelper.chatmasterveloz.com/docs-imagem/16527-envio-audio-1024x45.jpg)Clique no ícone de "Áudio" para iniciar a gravação.

![imagem](https://clihelper.chatmasterveloz.com/docs-imagem/16527-envio-audio-enviar-1024x44.jpg)Enquanto estiver gravando um áudio, você visualiza o **tempo** corrido, além de um botão para "**Cancelar**" e outra para "**Enviar**" o áudio.
