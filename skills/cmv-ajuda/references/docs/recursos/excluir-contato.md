# Excluir Contato

- **Fonte:** https://clihelper.chatmasterveloz.com/docs/excluir-contato
- **Categoria:** Recursos
- **Menu:** Contatos › Excluir Contato

---

Para **excluir** um contato, acesse o menu →Contatos > Ícone Lixeira

![imagem](https://clihelper.chatmasterveloz.com/docs-imagem/20236-contatos-excluir-1024x174.jpg)

> **[ATENCAO]**
>
> #### Atenção
>
> Ao excluir um contato, todos os seus atendimentos também serão removidos.
