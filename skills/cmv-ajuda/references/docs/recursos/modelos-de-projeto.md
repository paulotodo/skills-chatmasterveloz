# Modelos de Projeto

- **Fonte:** https://clihelper.chatmasterveloz.com/docs/modelos-de-projeto
- **Categoria:** Recursos
- **Menu:** Projetos › Modelos de Projeto

---

🧩 Toda entrega da sua empresa segue os mesmos passos, e mesmo assim cada projeto começa do zero? O **modelo de projeto** guarda as etapas e as tarefas que se repetem, com o prazo e o checklist de cada uma. Ao criar um projeto, você escolhe o modelo e ele já nasce pronto.

Ideal para:

☑️ **Implantação repetida:** Guarda os passos que toda entrega segue, na mesma ordem.

☑️ **Prazos combinados:** Conta o prazo de cada tarefa a partir do dia em que o projeto nasce.

> **[RESUMO]**
>
> #### Resumo Prático
>
> ➡️ Acesse o menu **Projetos**.
>
> ➡️ Clique em **Modelos** e depois em **Novo modelo**.
>
> ➡️ Dê o nome, monte as **Etapas** e as **Tarefas** e clique em **Salvar**.

## Como montar um modelo de projeto

Acesse o menu **Projetos  ›  Modelos  ›  Novo modelo**

🔘 **Nome do modelo:** o nome que aparece na hora de escolher o modelo, ao criar o projeto.

🔘 **Descrição:** um texto sobre o que o modelo entrega.

🔘 **Etapas:** as colunas do quadro do projeto, na ordem do trabalho. Cada etapa tem um nome e a caixa **Fecha a tarefa**; o botão **Etapa** acrescenta mais uma. A janela já abre com **A fazer**, **Fazendo** e **Feito**, com **Fecha a tarefa** marcada em **Feito**.

🔘 **Fecha a tarefa:** marque na etapa em que o trabalho termina. A tarefa que chega nessa etapa é dada como concluída; a que sai dela é reaberta.

🔘 **Tarefas:** o botão **Tarefa** acrescenta, na mesma janela, uma tarefa ao modelo, com o **Título da tarefa**, a **Etapa** em que ela começa, a **Prioridade** (Alta, Média ou Baixa), os **Dias** para o prazo e o **Checklist**, um item por linha.

🔘 **Ocultar o valor da venda para quem executa o projeto:** vale para o projeto que nasce do modelo quando a venda é ganha, em **Criar o projeto sozinho ao ganhar a venda**. Quem executa o projeto vê o que foi vendido, mas não por quanto; a gestão e quem vendeu continuam vendo o valor.

⚠️ O **Salvar** só libera com o **Nome do modelo** preenchido, e o modelo precisa de pelo menos uma etapa com nome. Sem ela, a tela avisa *"O modelo precisa de pelo menos uma etapa com nome."*

## Como o prazo da tarefa é contado

O campo **Dias** do modelo de projeto conta a partir do dia em que o projeto nasce. Uma tarefa com 2 dias, num projeto criado em 31/10, fica com o prazo de 02/11; uma com 7 dias, com o prazo de 07/11.

## O que o projeto leva do modelo

➡️ As etapas, na mesma ordem, com a marcação **Fecha a tarefa**.

➡️ As tarefas, cada uma na sua etapa, com a prioridade, o prazo contado do dia e o checklist, atribuídas ao responsável do projeto.

➡️ No projeto que nasce da venda ganha, a opção de ocultar o valor da venda de quem executa, quando ela está marcada no modelo.

## Apagar um modelo de projeto

Ao apagar um modelo, a plataforma pergunta: *Apagar o modelo? Os projetos que já nasceram dele continuam como estão.*

> **[DUVIDAS]**
>
> #### Dúvidas Comuns
>
> **O prazo das tarefas do modelo de projeto é uma data fixa?** Não. O campo **Dias** conta a partir do dia em que o projeto nasce do modelo, então cada projeto ganha as suas próprias datas.
>
> **Apagar um modelo de projeto apaga os projetos que nasceram dele?** Não. A janela de confirmação avisa que os projetos que já nasceram do modelo continuam como estão.
>
> **Mudei um modelo de projeto. Os projetos que já nasceram dele mudam?** Não. A mudança vale só para os projetos que nascerem do modelo dali em diante.
