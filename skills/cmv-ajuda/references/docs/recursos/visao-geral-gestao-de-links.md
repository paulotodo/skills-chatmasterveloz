# Visão Geral Gestão de Links

- **Fonte:** https://clihelper.chatmasterveloz.com/docs/visao-geral-gestao-de-links
- **Categoria:** Recursos
- **Menu:** Gestão de Links › Visão Geral Gestão de Links

---

🧩 **Visão Geral da Gestão de Links** é o painel de controle operacional onde você gerencia seus links, acompanha e monitora estatísticas de cliques.

![Visão Geral Gestão de Links](https://clihelper.chatmasterveloz.com/docs-imagem/28879-visao-geral-links.jpg)

## Topo

⚡ **Cabeçalho de Controle:** no topo direito da tela, você encontra as ferramentas de navegação:

🔘 **Buscar links:** campo de texto para digitar o nome do link.

🔲 **+ NOVO LINK:** botão para iniciar o cadastro de um novo Link.

## PARTE CENTRAL

⚡ **Lista de Links:** cada linha representa um link cadastrado no sistema, sendo composta por:

◽ **Nome:** rótulo cadastrado para esse link.

◽ **Link Curto:** url encurtada. Clique em cima para Copiar para área de Transferência.

◽ **Telefone:** número whatsapp para direcionar o link.

◽ **Cliques:** quantidade de cliques nesse link.

◽ **Status:** ativo ou inativo.

◽ **Criado em:** data de criação do link.

🔲 **Ícone Olho:** visualize as estatísticas detalhadas dos cliques nesse link.

🔲 **Ícone Lápis:** botão para editar um link.

🔲 **Ícone Lixeira:** botão para excluir um link.
