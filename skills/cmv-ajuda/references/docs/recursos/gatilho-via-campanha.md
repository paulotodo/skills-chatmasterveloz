# Gatilho via Campanha

- **Fonte:** https://clihelper.chatmasterveloz.com/docs/gatilho-via-campanha
- **Categoria:** Recursos
- **Menu:** FlowBuilder › Pontos de Entrada (Gatilho) › Gatilho via Campanha

---

🧩 **Gatilho via Campanha** é o método que permite conectar um fluxo em seus disparos em massa.

> **[RESUMO]**
>
> #### Resumo Prático
>
> ➡️ Acesse o menu **Campanhas** e, ao criar uma Campanha, selecione o **Setor** e o fluxo vinculado a ele.

## Como configurar o Gatilho de Fluxo via Campanha

#### ⚡ Passo 01 - O Fluxo

Acesse o menu → FlowBuilder e desenvolva seu fluxo.

#### ⚡ Passo 02 – O Setor

Acesse o menu **Setores & Chatbot** para criar ou editar um **Setor**. No campo **Fluxos de Automação**, selecione o fluxo desejado.

#### ⚡ Passo 03 - A Campanha

Acesse o menu **Campanhas** para criar uma Campanha.

Escolha o **Setor** que tem o fluxo desejado vinculado.

No campo "**Fluxos de Automação**" selecione o fluxo desejado — o mesmo vinculado ao Setor escolhido.

> **[DUVIDAS]**
>
> ### Dúvidas Comuns
>
> **Posso usar o mesmo fluxo para várias campanhas?** Sim.
>
> **Por que alguns blocos não funcionam no fluxo de Campanha?** Alguns blocos só funcionam com a conversa em “Aguardando”. Se a Campanha for acionada durante um **“Atendimento”**, esses blocos podem travar a automação.
>
> Você pode utilizar o bloco “Trocar de Fluxo” em seu fluxo atual, para que a conversa seja direcionada para o “Aguardando”, onde os blocos funcionam corretamente. **Atenção**: tenha em mente que a conversa sairá do atendimento de sua equipe.
