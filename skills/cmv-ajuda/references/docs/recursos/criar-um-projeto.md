# Criar um Projeto

- **Fonte:** https://clihelper.chatmasterveloz.com/docs/criar-um-projeto
- **Categoria:** Recursos
- **Menu:** Projetos › Criar um Projeto

---

🧩 Começar um projeto é dizer o que vai ser entregue, para quem, por quem e até quando. A janela **Novo projeto** reúne isso num lugar só e, com um modelo escolhido, o projeto já nasce com as etapas e as tarefas.

> **[RESUMO]**
>
> #### Resumo Prático
>
> ➡️ Acesse o menu **Projetos** e clique em **Novo projeto**.
>
> ➡️ Dê o nome e escolha o **Modelo**, o **Cliente**, o **Responsável** e a **Equipe**.
>
> ➡️ Clique em **Salvar**.

## Os campos do projeto

Acesse o menu **Projetos  ›  Novo projeto**

🔘 **Nome do projeto:** o nome que aparece na lista de projetos e no quadro.

🔘 **Modelo:** aparece quando a empresa tem modelos de projeto. O projeto nasce com as etapas e as tarefas do modelo escolhido; a opção **Sem modelo (etapas padrão)** cria o projeto sem tarefas, com as etapas **A fazer**, **Fazendo**, **Revisão** e **Feito**.

🔘 **Cliente:** o contato para quem o projeto é feito.

🔘 **Responsável:** quem responde pelo projeto.

🔘 **Situação:** **Planejamento**, **Em andamento**, **Pausado** ou **Concluído**. É por ela que a lista de projetos filtra.

🔘 **Equipe:** as pessoas que trabalham no projeto. A própria janela avisa: *Só a equipe (e a gestão) vê o projeto.* Quem cria o projeto e o **Responsável** entram na equipe sozinhos.

🔘 **Prazo:** a data de entrega do projeto.

🔘 **Cor:** a cor que identifica o projeto, numa faixa à esquerda dele na lista e ao lado do nome, no quadro.

🔘 **Descrição:** o que vai ser entregue, em texto livre.

🔘 **Anexos:** **Anexar arquivos** escolhe os arquivos do projeto. A janela lista os arquivos escolhidos e avisa: *Os arquivos são enviados ao salvar o projeto.*

🔘 **Ocultar o valor da venda para quem executa:** aparece na janela **Editar projeto** quando o projeto está ligado a uma oportunidade. A ajuda da tela explica: *O responsável e a equipe veem o que foi vendido, mas não por quanto. A gestão e o vendedor continuam vendo o valor.*

⚠️ O **Nome do projeto** é obrigatório: sem ele, a tela avisa *"Dê um nome ao projeto."* e nada é salvo.

## Criar o projeto pelo atendimento

No atendimento, o painel do contato tem a seção **Projetos**, com o botão **Novo projeto**: ele abre a mesma janela, com o **Cliente** já preenchido com o contato do atendimento, para criar o projeto sem sair da conversa.

## O que acontece ao salvar o projeto

➡️ Com modelo, o projeto nasce com as etapas e as tarefas do modelo, e o prazo de cada tarefa é contado a partir do dia da criação.

➡️ O projeto entra na lista do menu **Projetos** e, quando tem cliente, aparece no painel daquele contato.

➡️ Os arquivos de **Anexos** são enviados e aparecem no projeto, no painel **Sobre o projeto**, na aba **Descrição e anexos**.

➡️ Depois, o botão **Editar**, no quadro do projeto, abre a mesma janela para mudar qualquer campo.

> **[DUVIDAS]**
>
> #### Dúvidas Comuns
>
> **O campo Modelo não aparece na janela Novo projeto.** O campo **Modelo** só aparece quando a empresa tem pelo menos um modelo de projeto. Crie o modelo no menu **Projetos  ›  Modelos**.
>
> **O prazo das tarefas do projeto conta de quando?** Do dia em que o projeto é criado: uma tarefa de 7 dias num projeto criado em 31/10 vence em 07/11.
>
> **Quando os anexos do projeto são enviados?** Ao clicar em **Salvar**. Até lá, a janela do projeto só lista os arquivos escolhidos em **Anexos**.
>
> **Criei o projeto e não me coloquei na Equipe. Vou conseguir ver o projeto?** Sim. Quem cria o projeto e o **Responsável** entram na **Equipe** sozinhos.
