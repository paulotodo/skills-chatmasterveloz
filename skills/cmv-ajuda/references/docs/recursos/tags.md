## Tags

Categorizando com estilo

🧩 **Tags** são etiquetas personalizáveis que permitem categorizar, segmentar e automatizar o atendimento dentro do **Chat Master Veloz**. Elas funcionam como "carimbos" digitais para identificar clientes, conversas e etapas do funil de vendas.

☑️ **Organização Visual:** identifique rapidamente o status ou o perfil do cliente através de cores e nomes.

☑️ **Segmentação Inteligente:** classifique contatos para gerar relatórios precisos ou para disparar automações futuras.

☑️ **Controle de Fluxo:** defina etapas claras de trabalho (ex: "Em Aberto", "Aguardando Pagamento", "Suporte N1") para estruturar a rotina da equipe.
