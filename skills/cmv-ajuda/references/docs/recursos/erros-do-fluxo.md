# Erros do Fluxo

- **Fonte:** https://clihelper.chatmasterveloz.com/docs/erros-do-fluxo
- **Categoria:** Recursos
- **Menu:** FlowBuilder › Editor de Fluxos › Erros do Fluxo

---

🧩 Um fluxo que funcionou no teste pode tropeçar com cliente de verdade: uma API fora do ar, um bloco que não pôde enviar, um dado que não veio. A janela **Erros do fluxo** mostra esses tropeços, fluxo por fluxo, para você corrigir sem esperar alguém reclamar.

> **[RESUMO]**
>
> #### Resumo Prático
>
> ➡️ Acesse o menu **FlowBuilder Nativo**.
>
> ➡️ No card do fluxo, clique em **Ver erros deste fluxo**.
>
> ➡️ Escolha o período e o nível e confira a lista.

## Como abrir os erros de um fluxo

Acesse o menu **FlowBuilder Nativo**

No card de cada fluxo, o ícone **Ver erros deste fluxo** abre a janela **Erros do fluxo**, com o nome do fluxo no título. O mesmo atalho fica no menu **Mais opções  ›  Ver erros** do card.

## Os filtros

🔘 **Período:** **24 horas**, **7 dias** ou **30 dias**.

🔘 **Nível:** **Todos**, **Parou o fluxo** ou **Tolerado**.

◽ **Parou o fluxo:** o erro interrompeu a conversa naquele ponto.

◽ **Tolerado:** o fluxo registrou o problema e seguiu adiante.

🔘 **Atualizar:** busca de novo, para ver erros que acabaram de acontecer.

Sem erro no período, a janela fica sem lista.

> **[DUVIDAS]**
>
> #### Dúvidas Comuns
>
> **Qual a diferença entre Parou o fluxo e Tolerado nos Erros do fluxo?** **Parou o fluxo** é o erro que interrompeu a conversa ali. **Tolerado** é o que foi registrado, mas o fluxo seguiu.
>
> **Os Erros do fluxo mostram problemas do desenho, como bloco solto?** Não. Os erros são registrados quando o fluxo roda com clientes. Para problemas do desenho, use o **Verificar**, no editor.
