# Busca no Menu

- **Fonte:** https://clihelper.chatmasterveloz.com/docs/busca-no-menu
- **Categoria:** Recursos
- **Menu:** Meu Perfil › Busca no Menu

---

🧩 Você sabe o nome da tela, mas não lembra em que grupo do menu ela fica? A **Busca no Menu** encontra o item pelo nome enquanto você digita, sem abrir os grupos um por um.

O campo fica no topo do menu lateral, com o texto *"Buscar no menu…"*, e procura em todos os itens do seu menu, inclusive nos que ficam dentro de um grupo fechado.

Ideal para:

☑️ **Atalho pelo teclado:** Leva a uma tela com parte do nome dela e a tecla Enter, sem percorrer o menu com o mouse.

☑️ **Item de submenu:** Encontra o item que fica dentro de um grupo do menu sem que o grupo precise estar aberto.

> **[RESUMO]**
>
> #### Resumo Prático
>
> ➡️ Clique no campo **Buscar no menu…**, no topo do menu lateral.
>
> ➡️ Digite parte do nome da tela.
>
> ➡️ Clique no item encontrado, ou aperte **Enter** para abrir o primeiro da lista.

## Como a Busca no Menu funciona

🔘 **O que a busca procura:** o nome de cada item do menu e também a descrição dele. Acento e maiúscula não fazem diferença.

🔘 **Itens de submenu:** a busca traz também os itens que ficam dentro de um grupo do menu, mesmo com o grupo fechado.

🔘 **Enter:** abre o primeiro item encontrado. Digitar *respostas* e apertar **Enter**, por exemplo, abre as **Respostas Rápidas**.

🔘 **Limpar a busca:** com texto no campo, aparece um **X** (*Limpar a busca*) que apaga o que foi digitado e volta o menu inteiro. A tecla **Esc** faz o mesmo.

🔘 **Sem resultado:** a tela avisa *"Nenhum item do menu com esse nome."*

⚠️ A **Busca no Menu** só encontra o que o seu menu já tem. Cada pessoa acha apenas os itens que aparecem no menu dela, conforme o perfil e o que está liberado para ela. Para quem não tem **Conexões** no menu, por exemplo, digitar *conexoes* dá *"Nenhum item do menu com esse nome."*

> **[DUVIDAS]**
>
> #### Dúvidas Comuns
>
> **Digitei o nome de uma tela na Busca no Menu e apareceu "Nenhum item do menu com esse nome". Por quê?** A **Busca no Menu** procura só nos itens do seu menu. Se a tela não aparece no seu menu, ela também não aparece na busca. O que cada pessoa vê no menu depende do perfil dela: confira com o administrador da empresa.
>
> **Preciso abrir o grupo do menu para a Busca no Menu achar um item de dentro dele?** Não. A **Busca no Menu** encontra os itens de submenu com os grupos fechados.
>
> **Como volto ao menu completo depois de usar a Busca no Menu?** Clique no **X** do campo (*Limpar a busca*) ou aperte **Esc**.
>
> **A Busca no Menu encontra uma tela por uma palavra que não está no nome dela?** Pode encontrar. A busca procura também na descrição de cada item do menu, e não só no nome.
