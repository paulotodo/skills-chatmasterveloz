# Projetos

- **Fonte:** https://clihelper.chatmasterveloz.com/docs/projetos
- **Categoria:** Recursos
- **Menu:** Projetos

---

🧩 Sua equipe acompanha o que vem depois da venda em planilha, grupo de mensagens e lembrete de cabeça? Quando cada entrega tem várias etapas e várias pessoas, a tarefa esquecida vira prazo perdido e cliente cobrando.

O **Projetos** organiza esse trabalho na plataforma: cada projeto tem o cliente, o responsável, a equipe, o prazo e um quadro com as etapas, onde as tarefas andam até ficarem prontas. O que a empresa repete vira modelo, e o projeto já nasce com as etapas e as tarefas certas.

## Como o Projetos se organiza

⚡ **Visão Geral e Permissões** — o que cada parte da tela faz e quem vê cada projeto.

⚡ **Montar** — os modelos, com as etapas e as tarefas que a empresa repete, e o projeto que nasce sozinho.

⚡ **Tocar o projeto** — criar o projeto e levar as tarefas pelo quadro até o fim.

## O que decidir antes de começar

➡️ **As etapas do trabalho.** Cada projeto tem as suas etapas, e a etapa marcada como **Fecha a tarefa** dá como concluída toda tarefa que chega nela.

➡️ **Quem participa.** Só a equipe do projeto e a gestão veem o projeto.

➡️ **O que vira modelo.** O trabalho que se repete de cliente para cliente vira modelo, com as etapas, as tarefas, o prazo de cada uma e o checklist.

➡️ **O que o cliente fica sabendo.** O cliente do projeto pode receber uma mensagem quando o projeto entra numa situação, como **Em andamento** ou **Concluído**. A gestão escolhe as situações que avisam e o texto de cada uma.

> **[DUVIDAS]**
>
> #### Dúvidas Comuns
>
> **Qual a diferença entre um projeto e uma tarefa?** O projeto agrupa várias tarefas em etapas, com cliente, responsável, equipe e prazo. Cada tarefa do projeto continua sendo uma tarefa da plataforma e aparece também no menu **Tarefas**.
>
> **Preciso de um modelo para criar um projeto?** Não. O modelo só poupa trabalho no que se repete: o projeto nasce com as etapas e as tarefas dele. Sem modelo, as tarefas são criadas no quadro do projeto.
