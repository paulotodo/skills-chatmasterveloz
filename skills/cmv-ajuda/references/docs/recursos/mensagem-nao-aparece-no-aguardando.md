# Mensagem não aparece no Aguardando

- **Fonte:** https://clihelper.chatmasterveloz.com/docs/mensagem-nao-aparece-no-aguardando
- **Categoria:** Recursos
- **Menu:** Problema / Solução › Mensagem não aparece no Aguardando

---

#### PROBLEMA

Mensagem chega no celular, mas não está aparecendo no **Aguardando** na plataforma.

#### SOLUÇÃO

➡️ Se o ticket estiver “**Sem Fila**”, somente Administradores e Supervisores terão acesso. Usuários comuns não. Adicione uma fila inicial no menu Conexões, e depois confirme se o atendente tem acesso a essa fila.

➡️ Se for diferente de “**Sem Fila**”, confirme se o atendente tem permissão para visualizar essa fila, através do menu Equipe.
