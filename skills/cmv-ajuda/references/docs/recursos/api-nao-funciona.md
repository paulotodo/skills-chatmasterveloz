# API não funciona

- **Fonte:** https://clihelper.chatmasterveloz.com/docs/api-nao-funciona
- **Categoria:** Recursos
- **Menu:** Problema / Solução › API não funciona

---

#### PROBLEMA

Chamada API não funciona

#### SOLUÇÃO

➡️ **API Externa** deve estar habilitada em **Planos**.

➡️ A conexão deve ter um **Token** definido.

➡️ O Token da Conexão **não** pode ser igual ao token de outra conexão.

➡️ Teste uma chamada simples como a API **Status da Conexão**, para validar se obtém um retorno.

➡️ Confira o **Endpoint** e o **Método** (GET, POST, PUT, DELETE)

➡️ Confira o **Payload**, em especial string (com aspas) e number (sem aspas), conforme a documentação.
