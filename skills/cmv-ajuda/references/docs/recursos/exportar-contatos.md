# Exportar Contatos

- **Fonte:** https://clihelper.chatmasterveloz.com/docs/exportar-contatos
- **Categoria:** Recursos
- **Menu:** Contatos › Exportar Contatos

---

Para **exportar** contatos acesse o menu →Contatos > Importar / Exportar

![imagem](https://clihelper.chatmasterveloz.com/docs-imagem/20433-contatos-importar-exportar-1024x232.jpg)Antes de exportar você pode optar por filtrar a lista por "**Tags**" e/ou por "**Filas / Setores**", podendo inclusive adicionar mais de um filtro de cada tipo.

![imagem](https://clihelper.chatmasterveloz.com/docs-imagem/20433-contatos-exportar-filtros-1024x379.jpg)

> **[DICA]**
>
> #### Dica
>
> Para exportar “**todos**” os contatos, deixe os campos de filtro vazio.
>
> Nosso sistema irá exportar uma planilha "**.csv**" com ▫️Nome, ▫️Email, ▫️Número, ▫️Tags e ▫️Filas desses contatos.
