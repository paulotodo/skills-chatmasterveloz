# Concluir Tarefa

- **Fonte:** https://clihelper.chatmasterveloz.com/docs/concluir-tarefa
- **Categoria:** Recursos
- **Menu:** Tarefas › Concluir Tarefa

---

🧩 **Concluir Tarefa** serve para marcar uma atividade como concluída, sinalizando para a equipe e para o sistema que aquela demanda foi entregue.

☑️ **Organização:** mantenha o foco apenas nas pendências, permitindo filtrar e ocultar o que já foi resolvido.

☑️ **Rotina sem retrabalho:** na tarefa que se repete, concluir já cria a próxima na data certa.

> **[RESUMO]**
>
> #### Resumo Prático
>
> ➡️ Acesse o menu **Tarefas**.
>
> ➡️ Na lista de Tarefas, clique no ícone **concluir** (✅) de uma tarefa específica.
>
> ➡️ O título da tarefa ficará riscado.

## Como concluir uma Tarefa

Acesse o menu **Tarefas** e clique no ícone **Concluir** da tarefa.

![Como marcar uma Tarefa como concluída](https://clihelper.chatmasterveloz.com/docs-imagem/26222-tarefas-concluir.jpg)

🔘 **Check:** clique no check (✅) para marcar uma tarefa como concluída.

Imediatamente o título da tarefa aparecerá riscado e o painel será atualizado!

## Tarefa que se repete

Na tarefa com **Repetir**, concluir cria a próxima tarefa na data seguinte do **Padrão de Recorrência** — na tarefa diária, o dia seguinte —, no mesmo horário, pendente e com a mesma repetição. A tela avisa *"Tarefa concluída. A próxima foi criada para"* e a data.

A tarefa concluída continua na lista, riscada, e a próxima aparece como pendente. No **Histórico** de cada uma, a concluída registra a repetição, e a nova registra que foi *Criada pela repetição da tarefa* anterior.

> **[DUVIDAS]**
>
> #### Dúvidas Comuns
>
> **Finalizei por engano, como desfazer?** Clique novamente no ícone de **Concluir** (✅). A tarefa deixará de estar riscada e voltará para o status de pendente.
>
> **A tarefa sumiu após finalizar:** Verifique os **Filtros**. Se o filtro estiver configurado para mostrar apenas "Pendentes", as tarefas concluídas ficarão ocultas. Mude o filtro para "Todas" ou "Concluídas".
>
> **Concluí uma tarefa que se repete. Preciso criar a próxima?** Não. Ao concluir, a próxima já nasce na data seguinte da repetição, no mesmo horário.
>
> **Quem pode finalizar?** Qualquer usuário com acesso à tarefa (Criador, Responsável ou Compartilhado) tem permissão para alterar o status de conclusão.
