# Atender pelo Web Chat do seu site

- **Fonte:** https://clihelper.chatmasterveloz.com/docs/atender-pelo-web-chat-do-seu-site
- **Categoria:** Trilhas
- **Menu:** A cobrança do WhatsApp Oficial mudou › Atender pelo Web Chat do seu site

---

🧩 O que não passa pelo WhatsApp a Meta não cobra. O nosso **Web Chat** é uma janela de conversa dentro do seu próprio site: o visitante escreve ali, e a conversa chega na nossa plataforma junto com os outros canais — sem passar pela Meta.

## Web Chat

![Ilustração do Web Chat: o visitante conversa por uma janela de chat no próprio site e a conversa chega na plataforma sem passar pela Meta, portanto grátis.](https://clihelper.chatmasterveloz.com/docs-imagem/ed-6aa442b33e76e.png)

O ganho não é tirar do WhatsApp quem já está lá — é **não empurrar para o WhatsApp quem chegou pelo site**. Onde hoje há um botão de WhatsApp na sua página, a conversa inteira sai pelo canal oficial e entra na conta; com o Web Chat, ela acontece ali mesmo.
